# Entregables por etapa

En esta carpeta organizamos los entregables correspondientes a las cinco etapas del proyecto de Comercial Horizonte. Cada una cuenta con un README que permite acceder a los archivos, resultados y evidencias del trabajo realizado.

Las entregas se fueron complementando a medida que avanzamos con el proyecto. Por eso, cada etapa incluye lo trabajado anteriormente y agrega los resultados de las nuevas actividades, sin necesidad de duplicar los archivos.

- [E1 Calidad](https://github.com/alexisbociello/trabajoFinalModulo6/blob/main/10_Entregables_por_etapa/E1_Calidad/README.md): revisión inicial de los datos, identificación de errores y diagnóstico de calidad.

- [E2 Pipeline y pruebas](https://github.com/alexisbociello/trabajoFinalModulo6/blob/main/10_Entregables_por_etapa/E2_Pipeline_y_pruebas/README.md): desarrollo del pipeline en Python y pruebas para comprobar su funcionamiento.

- [E3 Agente analista](https://github.com/alexisbociello/trabajoFinalModulo6/blob/main/10_Entregables_por_etapa/E3_Agente_analista/README.md): configuración y evaluación del agente analista para interpretar los resultados.

- [E4 Docker y versiones](https://github.com/alexisbociello/trabajoFinalModulo6/blob/main/10_Entregables_por_etapa/E4_Docker_y_versiones/README.md): ejecución del proyecto en Docker y comparación de resultados con las ejecuciones en Python.

- [E5 Supervisión y cierre](https://github.com/alexisbociello/trabajoFinalModulo6/blob/main/10_Entregables_por_etapa/E5_Supervision_y_cierre/README.md): pruebas de supervisión y recuperación, elaboración del informe final y organización de los archivos para la entrega.
